# Repository Structure Specification

> Status: Verified against current codebase and implementation
> Source: `docs/REPOSITORY_STRUCTURE.md`

## Problem

Repository structure guidance is concise and should be discoverable in the same spec catalog as other engineering artifacts.

## Goal

Capture repository layout contract and navigation expectations in normalized superpowers spec format.

## Scope

### In Scope

- Top-level repository organization description
- Structural conventions intended for contributors

### Out of Scope

- Detailed per-module architecture
- Build/test command documentation (covered elsewhere)

## Design Summary

- Source is compact and organizational.
- This spec preserves layout intent and contributor orientation value.

## Success Criteria

- Repository structure guidance is easy to discover and reference.
- New contributors can quickly map major directories to responsibilities.
