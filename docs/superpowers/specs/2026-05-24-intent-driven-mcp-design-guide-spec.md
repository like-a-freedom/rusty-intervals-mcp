# Intent-Driven MCP Design Guide Specification

> Status: Verified against current codebase and implementation
> Source: `docs/INTENT_DRIVEN_MCP_DESIGN_GUIDE.md`

## Problem

External design references are extensive and hard to consume as actionable internal guidance.

## Goal

Normalize curated intent/skills-driven MCP references into a compact knowledge spec for architecture and design decisions.

## Scope

### In Scope

- Official and industry reference mapping
- Practical patterns relevant to MCP intent/skills design
- Enterprise architecture context for decision support

### Out of Scope

- Reproducing full external articles verbatim
- Enforcing one vendor-specific methodology

## Design Summary

- Source acts as curated bibliography with practical framing.
- References span official guidance, implementation patterns, and enterprise viewpoints.
- Spec preserves decision-support utility while reducing navigation overhead.

## Success Criteria

- Team can quickly map design decisions to documented external evidence.
- Guide remains usable as a lightweight architecture reference index.
- Reduces duplicated research effort across iterations.
